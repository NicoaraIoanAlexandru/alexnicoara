# Alex Nicoară Studio — Project Rules

## Project Vision

This project is the personal brand and commercial portfolio of Alex Nicoară.

The goal is to create a premium bilingual website that converts visitors into clients.

## Positioning

Alex Nicoară:

AI Product Developer | Cybersecurity Engineer | Digital Builder

Brand message:
Building digital products. Securing systems. Challenging limits.

## Technical Standards

Always prioritize:

- clean architecture
- maintainable code
- accessibility
- SEO
- performance
- responsive design
- security best practices

## Technology Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- next-intl
- Framer Motion

## Design Principles

The visual identity is:

Premium Technical

Characteristics:

- dark theme
- minimalist
- elegant animations
- technology meets ocean
- no generic templates

## Development Rules

Before creating components:

- check existing architecture
- reuse components
- avoid duplication
- keep components small
- prefer composition over complexity

## Business Context

This website is not only a portfolio.

It is a commercial product designed to generate:

- digital product clients
- AI consulting opportunities
- cybersecurity consulting opportunities

Every design decision should consider conversion and trust.

## Internationalization

This project supports Romanian and English from the beginning.

Never hardcode user-facing text.

All visible content must support translation through next-intl messages.

## UI Architecture

Build reusable components before creating page-specific solutions.

Prefer:

- reusable UI primitives
- consistent spacing
- design tokens
- composition patterns

Avoid:

- duplicated Tailwind classes
- one-off styling
- inconsistent layouts

## Conversion Principles

The website should always optimize for:

- trust
- credibility
- clarity
- client conversion

Technical details should support business outcomes, not replace them.
